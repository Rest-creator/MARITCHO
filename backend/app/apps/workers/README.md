# Workers App

## Overview
The Workers app manages worker-specific data, including profiles, vetting processes, standings, and performance metrics.

## Responsibilities
- **Worker Profiles**: Storing detailed information about individual workers (skills, trades, grades, next of kin, guarantors).
- **Vetting**: Managing progressive vetting tiers (e.g., identity verification, skill checks, reference checks).
- **Standing & Performance**: Computing and tracking ongoing worker metrics such as dispute rates, on-time rates, and overall platform standing.
- **Disputes**: Managing and logging worker disputes.
