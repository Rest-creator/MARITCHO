# Accounts App

## Overview
The Accounts app is responsible for managing user identities, authentication, authorization, and role management within the Maricho platform.

## Responsibilities
- **User Management**: Creating, updating, and managing user profiles.
- **Authentication & Authorization**: Handling login, token generation (JWT), and access control based on user roles (e.g., Buyer, Worker, Operations).
- **Security**: Password hashing, token validation, and securing endpoints.
